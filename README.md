# Family-card-game by SSK

MK Projectのカードを使って遊ぶ、カードバトルゲームです。

最初は3枚のカードで、文字だけで遊べるゲームから作ります。

## 最初のカード

| 名前 | HP | 攻撃 | 防御 | 属性 |
| --- | ---: | ---: | ---: | --- |
| ミドニャ | 150 | 50 | 30 | 草 |
| ミズニャ | 150 | 30 | 50 | みず |
| ヒエンギョ | 130 | 70 | 30 | 炎 |

## 属性

有利な属性で攻撃すると、ダメージが `+10` されます。

```text
炎 → 草 に強い
草 → みず に強い
みず → 炎 に強い
```

## 行動

毎ターン、行動を1つ選びます。

### 攻撃

```text
通常攻撃 = 10 + 攻撃力 / 10
```

属性が有利なら `+10` されます。

### 防御

```text
防御 = 10 + 防御力 / 10
```

このターンに受けるダメージを減らします。

### 溜め

このターンは強い行動の準備をします。

溜め中の効果:

```text
耐えられるダメージ +30
貫通攻撃を受けても、防御を無視されない
```

次のターンに選べる行動:

```text
強攻撃: +30ダメージ
貫通攻撃: 相手の防御を無視
```

注意: 溜め中でもダメージは受けます。無敵ではありません。

### カウンター

相手が攻撃してきたら、そのダメージを相手に跳ね返します。

```text
自分も1ダメージ受ける
```

## 遊び方

### ブラウザ版

`index.html` をブラウザで開くと、カードとボタンで遊べます。

### 文字版

Pythonで動かします。

```powershell
python game.py
```
