# Family-card-game by SSK

MK Projectのカードを使って遊ぶ、カードバトルゲームです。

最初は3枚のカードで、文字だけで遊べるゲームから作ります。

## 最初のカード

| 名前 | HP | 攻撃 | 防御 | 属性 |
| --- | ---: | ---: | ---: | --- |
| ミドニャ | 150 | 50 | 30 | 草 |
| ミズニャ | 150 | 30 | 50 | みず |
| ヒエンギョ | 130 | 70 | 30 | 炎 |

## 属性

有利な属性で攻撃すると、ダメージが `+10` されます。

```text
炎 → 草 に強い
草 → みず に強い
みず → 炎 に強い
```

## 行動

毎ターン、行動を1つ選びます。

### 攻撃

```text
通常攻撃 = 10 + 攻撃力 / 10
```

属性が有利なら `+10` されます。

### 防御

```text
防御 = 10 + 防御力 / 10
```

このターンに受けるダメージを減らします。

### 溜め

このターンは強い行動の準備をします。

溜め中の効果:

```text
耐えられるダメージ +30
貫通攻撃を受けても、防御を無視されない
```

次のターンに選べる行動:

```text
強攻撃: +30ダメージ
貫通攻撃: 相手の防御を無視
```

注意: 溜め中でもダメージは受けます。無敵ではありません。

### カウンター

相手が攻撃してきたら、そのダメージを相手に跳ね返します。

```text
自分も1ダメージ受ける
```

## 遊び方

### ブラウザ版

`index.html` をブラウザで開くと、カードとボタンで遊べます。

ルミナビーストのカードコレクション側から書き出した、バトル用カードファイルを読み込めます。

対応形式:

```text
format: lumina-battle-export-v1
```

このゲームでは、カードファイルの `cards` 配列に入っている入手済みカードだけを表示します。
未入手カードを推測するためのマスターカード一覧や空スロットは使いません。

表示する内容:

```text
画像
名前
属性
レア度
所持枚数
ステータス
進化元
```

進化後も、進化前のカードはコレクションに保存する前提です。

### チーム編成

カード一覧タブは作らず、バトル画面側でチーム編成をします。

```text
デッキ枚数: 最大5枚
同じカード: 所持枚数まで
開始ボタン: いざ勝負
```

チームは複数作れます。

```text
チームを選ぶ
新しいチーム
チーム削除
```

GODカードはバトル用カードとして読み込まず、チームにも入れません。

対戦方法:

```text
CP対戦: 自分のデッキと同じレア度構成でCPUデッキを作る
二人対戦: 1Pと2Pが自由にデッキを作る
```

CP対戦の例:

```text
自分: ノーマル / ノーマル / ノーマル / レア / スーパーレア
CPU : ノーマル / ノーマル / ノーマル / レア / スーパーレア
```

属性はそろえません。

### 特訓場

特訓場タブでは、カードのステータスを調整できます。

```text
HP
攻撃
防御
すばやさ
```

合計値がレア度の基準と違う場合は、カードに「設定を変えてください」と表示します。

基準:

```text
ノーマル: 150
レア: 200
スーパーレア: 300
ウルトラレア: 500
```

### 技選択

カードをデッキに入れるとき、属性とレア度に合わせた技名を選べます。

```text
炎: ひのこ / 火 / ファイヤーボール / 炎 / ウルトラファイヤー
水: 水鉄砲 / 水をかける / バブルビーム / うずまき / ハイプレッシャーウォーター
草: このは / サイコリーフ / フュージョンリーフ / エナジーボール / リーフストーム
電気: ビリビリ / 静電気 / カミナリ / 感電ショッカー / サンダーハリケーン
星: 星のかけら / スターがん / ビッグスター / 流れ星 / スターラッシュ
```

ウルトラレア技:

```text
炎: ボルケーノ・オーバードライブ
水: ハイドロ・インフィニティ
草: グリーン・オーバーフロー
電気: ライトニング・エクスキューション
星: ギャラクシー・リベレーション
```

### 文字版

Pythonで動かします。

```powershell
python game.py
```
